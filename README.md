# Welcome to the Official JaxLUG™ Webpage Redirect Repository

This repository purpose is to redirect traffic from jaxlug.github.io to the
official website jaxlug.ngo, externally hosted on a Linux server.

## Community Collaboration

The website is a collaboration effort among all the members of the JaxLUG group.
It also works as a main point of information for the JaxLUG meetings and events.

## Interested in collaborating?

Please, open an issue and/or reach out via [email](mailto:admin@jaxlug.ngo) for
approval. Once confirmed, writer access will be granted to your Github account
to allow you to make changes and submit pull requests to the official
members only private git repository for the website.
